# Character packs

Converted by `tools/makehuman/*.py` from MakeHuman data released under CC0 1.0
(public domain): the base mesh, morph targets and default skeleton
(github.com/makehumancommunity/makehuman, `makehuman/data`), and the community
asset packs from makehumancommunity.org (skins, clothes and accessories).
Only data files are used; none of MakeHuman's (AGPL) program code is included.

Left out on purpose: anatomical "with genitals" skins, make-up skins, costume
items (superhero, pirate, Christmas) and political merchandise.
