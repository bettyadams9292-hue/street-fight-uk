# Property kit: sources

Every model in this folder is **original work for Street Fight UK** (no downloaded assets).
They are built from code by the scripts in `tools/models/property/` (`glb.py` writes flat-shaded
low-poly GLB; `mansions.py`, `gates.py`, `fittings.py`, `rooms.py` build the pieces). Run
`python3 tools/models/property/<script>.py` to regenerate into `/tmp/property/out`.
