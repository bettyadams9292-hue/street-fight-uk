# UI icons (public/icons/ui)

All 52 SVGs here are original work drawn for Street Fight UK (no icon font,
library or download). Licence: original work for Street Fight UK.

Style: 24 x 24 viewBox, fill none, stroke currentColor, stroke-width 2,
square caps, mitred corners. Child elements carry no stroke or colour
attributes, so the map can restyle the paths it embeds.

After adding or editing an SVG, run `python3 tools/icons/build_icons.py`
to regenerate `src/ui/iconArt.ts` (tests/icons.test.ts checks they agree).
